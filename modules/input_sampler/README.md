# input_sampler

通过 `CONFIG_INPUT_SAMPLER` 启用，依赖 `analog_input` 和 `gpio` 的数字输入能力。
模块按调用者提供的通道、数字输入分组和缓冲区执行一次采样，不读取产品设备树节点，
不固定通道数，不解释地址、工程单位或测点。

`input_sampler_init()` 初始化配置中的数字输入组及可选模拟输入组。
`input_sampler_read()` 先检查缓冲区容量，再按配置顺序读取各数字组和模拟组。
配置可以只提供模拟输入，也可以只提供数字输入；输出缓冲区和配置均由调用者持有。
调用者负责串行访问同一硬件，不在采样期间修改配置。

成功时 `sample.valid=true`；失败时返回底层错误并使其为 false，部分输出不可作为有效样本使用。
不创建线程、不分配输出内存。产品硬件装配见应用的 `app/acquisition/config.c`，
拨码地址解释与产品采样布局也归应用。

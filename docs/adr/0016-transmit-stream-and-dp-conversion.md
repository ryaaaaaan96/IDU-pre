# 0016：统一接收输入、锁定协议与 DP 整数转换

状态：accepted，2026-10-31；设计已确认；DP 类型转换已实现，通信模块尚未实现。

重新接入对外从机协议时采用 transmit、modbus、vport 三模块，APP 持有线程和物理接入。
以统一字节和事件输入支持内容判帧与时序判帧，transmit 持有缓存并按登记顺序锁定、
仅在解析不匹配时环形切换，接受首次匹配延迟以减少重复探测；有限期限和长度限制避免无限等待。
这取代 ADR 0014 删除通信后的能力范围选择，不直接恢复历史实现。

四个 DP key/index 读写接口增加显式输入/输出类型，将整数转换集中在 DP，
避免协议侧重复配置和缓存内部类型；协议侧保留放缩、偏移及字序，业务回调使用内部类型。
该决定替代“内外类型必须一致”、DP 元信息查询及 transmit needs_conversion 的讨论提案，
实现后无类型读写入口已删除，应用和测试调用方均显式传类型。完整约束见[设计方案](../transmit-design.md)。

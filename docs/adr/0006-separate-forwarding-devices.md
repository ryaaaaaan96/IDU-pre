# 0006：数据设备与虚拟转发设备分开配置

状态：已接受，2026-10-22；实现待关联任务完成。用户认可两类配置的结构示例并要求发布规格。
本决定替代 ADR 0003 中将北向协议段挂在本地数据设备上的装配选择，其余升级协议行为继续有效。

数据设备声明 process 和可选 collect；虚拟转发设备声明北向逻辑口、转发表、协议段与广播策略。
虚拟转发身份与数据设备身份分开，不要求 process 表，不复制缓存，转发行引用原数据设备的信号。
TR 按当前入口选择读写映射及协议段，允许不同入口复用地址；北向站号继续在运行时由拨码输入提供。

应用维护实际字段，模块完成登记解析、校验和执行视图装配，替代七槽占位及重复服务关联。
接受修改装配和转发接口的成本，以消除本地设备与北向入口混用、全局映射无法隔离的限制。
当前数据键、参数存储、process 回调、采集周期及 IAPv3 线协议不变；不新增同物理口多站号分派。

完整验收依据见[规格](../../.scratch/forwarding-devices/spec.md)，实施任务标记为 ready-for-agent。

# 0006：数据设备与虚拟转发设备分开配置

状态：已实施，2026-10-22。用户认可两类配置的结构示例，按正式规格完成运行迁移。
本决定替代 ADR 0003 中将北向协议段挂在本地数据设备上的装配选择，其余升级协议行为继续有效。

数据设备声明 process 和可选 collect；虚拟转发设备声明北向逻辑口、转发表、协议段与广播策略。
虚拟转发身份与数据设备身份分开，不要求 process 表，不复制缓存，转发行引用原数据设备的信号。
TR 按当前入口选择读写映射及协议段，允许不同入口复用地址；北向站号的原运行期拨码要求已由文末所述初始化取号决定替代。

应用维护实际字段，模块完成登记解析、校验和执行视图装配，替代七槽占位及重复服务关联。
接受修改装配和转发接口的成本，以消除本地设备与北向入口混用、全局映射无法隔离的限制。
当前数据键、参数存储、process 回调、采集周期及 IAPv3 线协议不变；不新增同物理口多站号分派。

完整验收依据见[规格](../../.scratch/forwarding-devices/spec.md)，实施与验证记录见[关联任务](../../.scratch/forwarding-devices/issues/01-separate-data-and-forwarding.md)。

后续变更：北向必须在运行期由拨码更新的要求，由 [ADR 0007](0007-protocol-assembly-lifecycle.md)
及[协议编排重构规格](../../.scratch/communication-boundaries/spec.md)的初始化取号规则替代，已在本次协议迁移中实现。
本决定的数据归属、转发身份及按入口隔离规则继续有效。

## 2026-10-27：北向空闲不作为接口故障

按用户要求，上位机未连接或长期不发送请求属于正常空闲，不告警、不自动重建接口。删除此前按 20 秒无活动调用恢复的策略；维护超时仅用于处理阻塞和重配置逾期，显式参数重配置与显式恢复保持。北向请求活动统计不作为强制恢复依据。

# 0004：默认值、范围与恢复策略归处理点表行

状态：已接受，2026-10-21。用户允许处理表偏离参考结构，以减少重复配置。

`DM_SIG_CFG_S` 增加行内 `DM_SIG_DATA_S data`，范围与恢复开关统一在 `sig_flag` 中，与类型、
业务回调共同定义一个点。删除 IDU 的平行 `parameters[]`、行宏与默认值查表桥接，
由 DP 直接解释 Flash 配置。选择内嵌值而非可选参数指针，使每点配置能在同一处直接阅读；
接受无特殊默认值的行也占少量 Flash，表和数组初值均不复制到 RAM。

持久参数默认允许恢复，`FLAG_NO_RESTORE` 仅禁止主动恢复，已有 NVS 快照仍优先。
不增加默认 false 的独立布尔字段，避免改变旧表和 NVS schema。
`FLAG_RANGE_CHECK` 同时启用行内上下限，未开启时使用类型范围；开启且双零时只允许零。
旧回调保留非零上下限隐式检查规则，避免破坏独立消费者。
不改变五个现用持久点的键、类型、宽度、顺序或派生存储标志。

国家差异通过 DP 的可选只读覆盖入口提供；通用配置留在处理点表，已知国家缺项回退。
国家在初始化前固定，成功初始化后不可切换。查询不会改变当前值或 NVS；未来选择
不同国家仍需明确现有参数的范围校验和迁移策略，不自动覆盖已保存参数。
旧默认/范围回调作为独立消费者的适配保留，与国家覆盖互斥；IDU 不再注册它们。

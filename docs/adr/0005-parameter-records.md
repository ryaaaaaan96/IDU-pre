# 0005：参数独立存储，格式不兼容时重新初始化

状态：已接受，2026-10-21。取代 ADR 0002、0004 中保留整体快照格式和全表签名的约束。
用户明确不保留旧版快照，并要求读取格式不符合当前版本时自动清空、记录后重新初始化。

持久值按 `(dev_id, sig_id)` 分别写入 NVS，默认值、上下限和回调留在 const process 表。
完整逻辑键写入记录，并在 1024 个槽中通过哈希及线性探测解决 NVS 16 位 ID 的容量限制。
新增、删除或重排行不再影响其他参数；停用键暂留以保留身份，不做自动逐键回收。
多参数事务先持久化仅含变化值的临时日志，再分别写入；重启先补完日志，避免部分提交。
接受每记录的元数据开销和临时日志写放大，以换取独立身份及批量恢复保证。

不保留旧快照解析器或 schema 授权字段。遇到旧快照、未知版本、错误结构或不可转换的
类型/长度时，清空应用提供的整个参数分区，警告日志及 STORAGE_RESET 状态记录本次动作，
重新加载当前默认值。清空意味着本分区所有设定值及未决意图丢弃，不重放设备写入。
只重试一次，Flash I/O 故障和范围校验失败不自动清空；其他 Flash 分区不受影响。

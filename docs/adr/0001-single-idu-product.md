# 0001：只维护 IDU 产品方案

- 状态：已接受
- 日期：2026-10-21

## 背景

应用原有 AIDC 测试产品开关，涉及额外设备、处理/采集/转发表、参数默认值、
串口参数回调和虚拟 DSP。它已经不用于产品，仍使业务配置存在多套条件分支。
用户明确要求删除相关内容，并明确 IDU 是产品方案，IAPv3 是升级模块。

## 决定

1. `app/` 只维护 IDU 产品的设备、点表和业务。删除 AIDC 专用开关、条件分支、
   信号定义、业务回调、虚拟模型、测试套件、导入工具及来源快照。
2. 原 IDU 分支直接参与编译；不把已停用的 AIDC 分支改成无条件启用。
3. 删除板级 AIDC 专用 NVS 分区及别名；该区域暂不分配，也不主动擦除旧数据。
   IDU 的五个持久参数及现用 NVS、IAP、MCUboot 分区位置保持不变。
4. IAPv3 保留独立配置。IAPv3、SMP 和关闭上传入口都是 IDU 的升级功能选项，
   不切换产品业务点表。
5. 通用 DP/CO/TR 接口、模型采集能力及独立测试继续保留，不因删除产品分支而裁掉。

## 结果与验证

新增产品测点直接维护现有三张表和设备关联，无需选择产品 profile。
历史审计与验证记录保留原时点含义，已删除文件通过 Git 历史查询。

使用现有主机和 native_sim 回归验证点表、转发、参数保存及重启恢复，
并重新构建 IDU 固件检查配置、分区、签名与升级镜像。
桌面验证结果见[验证说明](../testing.md)，不代替实板验证。

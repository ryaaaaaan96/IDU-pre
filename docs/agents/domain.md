# 领域文档约定

本项目采用单一领域布局。仓库根目录指 `applications/IDU-pre/`；
West 工作区中的上游仓库不作为本项目的其他业务领域。

## 阅读顺序

- 如有 `GLOSSARY.md`，先读取相关术语。
- 如有 `docs/adr/`，读取与本次工作相关的架构决策。
- 结合现有 `docs/` 下的协议、点表、构建及测试文档理解实现。
- 术语表或 ADR 尚不存在时直接继续，不创建占位文件；
  在实际明确术语或形成架构决策时再按需建立。

## 使用规则

- 任务、规格、代码说明和测试沿用术语表定义的名称。
- 中文说明保留 `dp_*`、`co_*`、`tr_*` 等实际接口标识符。
- 新概念先核实是否已有对应术语，避免同义名称重复。
- 与已有 ADR 冲突时，明确指出对应决策及重新评估的原因，
  不静默覆盖。
- 领域文档与代码一同纳入本地 Git 管理。

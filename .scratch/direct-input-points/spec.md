# 本地硬件输入直接写测点

用户要求：采样代码只读取 DI/AI 并用 dp_set 写相应测点；硬件 spec 与 device_id、signal_id
放在同一配置结构。用户确认 16 路 DI 保持一个位图，AI 各自独立写点；暂不使用 address_pins。
后续要求电流换算直接放进 acquisition.c，不保留独立函数或文件。

实现：ADC 每行包含 spec、device_id、signal_id，DI 位图整体绑定设备和信号。
按名称读取硬件，平均后内联换算、饱和并同步写点。删除本地样本结构、异步批次发布、
工作区和细分运行阶段；主循环保留准入、通信状态及镜像/看门狗维护。
每点独立写入，后续失败不会撤销已完成的点；硬件地址不读取也不写点。

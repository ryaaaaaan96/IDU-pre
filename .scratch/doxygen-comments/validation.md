# 中文 Doxygen 接口注释

Status: resolved

## 范围

按用户确认的规则，将应用接口头文件及模块公开 include 目录中的既有说明转换为中文
Doxygen 风格，共涉及 46 个头文件。内部源码注释保持简短的实现说明，内部实现头文件
及脚本不统一套用 Doxygen 标签。

- 每个接口头文件增加 `@file` 与中文摘要。
- 接口说明使用 `/** ... */` 和 `@brief`；成员后置说明使用 `/**< ... */`。
- 保留已有契约的详细说明，将跨接口约束归入文件说明，调整原来位于宏前或文件末尾的
  通用说明，避免生成文档时挂到不相关的声明上。
- status 补充阶段、故障、任务配置、快照及成员说明，并为接口补充实际参数、返回值、
  初始化条件和线程／ISR 约束。
- 模拟量、数字量、组合输入、外部看门狗、RTU 编解码与镜像确认接口补充参数和结果约束。
- 不增加空泛参数模板，不在源文件重复完整接口文档；不改声明、接口参数或执行逻辑。

格式依据：[Doxygen 注释块](https://www.doxygen.nl/manual/docblocks.html)和
[特殊命令说明](https://www.doxygen.nl/manual/commands.html)。

## 验证

- 对照修改前快照，46 个头文件移除注释后的代码 token 序列完全一致。
- 静态检查 339 个 Doxygen 注释块的基本格式、标签及文件声明。
- 41 处 `@param` 均与后续接口声明的参数名称匹配。
- `git diff --check` 通过。
- 当前环境未安装 Doxygen，未执行 HTML/XML 文档生成，也未宣称通过生成器告警检查。
- 本轮仅修改注释，未重复固件构建或运行测试，未烧录实板。

快照、检查脚本及结果保存在工作区 `build/IDU-pre/doxygen-comments/`，不提交生成物。

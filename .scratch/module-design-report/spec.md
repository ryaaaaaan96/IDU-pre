# 通用模块设计汇报

## 目标

为领导汇报整理可离线打开的 HTML，先总体介绍，再介绍各通用模块，最后列出 TODO。
初版基于 6faba2f；当前报告以 6ecdf3e 的实际实现和模块契约为事实来源，
对应 Zephyr v4.5.0、SDK 1.0.1。

## 范围

- 总体目标、分层架构、依赖与线程归属。
- common、dataprocess、vport、transmit、modbus、watchdog、iap、quicklz、gd32e505。
- 产品组合链路、已实现能力、既有验证证据与实板待验边界。
- 建议 TODO 优先级，不承诺排期或未量化收益。
- 单文件 HTML，内嵌样式、离线可用、响应式排版、浏览器打印。
- 各模块补充设计理由、API 用途及约束、实际头文件声明和调用示例。
- 示例按目标固件参数做语法检查；物理适配与业务生命周期由 APP 实现。
- 文档采用正式报告用语与 A4 版式，提供 Word 文档；完整声明集中在附录。
- 同步 4.5.0 Modbus 适配、专项测试和固件资源数据，完整回归与实板验收保留为待办。

不修改产品代码，不把历史 collect 功能算作当前实现，不重新运行固件测试。

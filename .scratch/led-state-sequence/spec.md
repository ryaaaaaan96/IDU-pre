# LED 状态与内部步骤循环

status.c 选择 LED 指示状态；status_led.c 不查询整机阶段，每个指示状态维护独立的亮灭/毫秒步骤表，一个 delayable work 顺序执行，末尾回到首步。重复状态不重启，切换状态从首步开始；0 毫秒保持电平。排队延迟不跳步骤，不增加线程、定时器或消息队列。

保留启动慢闪、运行快闪、终止常亮和初始化错误策略；提供快闪两次慢闪一次并停顿的 ATTENTION 图案，暂不绑定产品业务条件。请求状态使用原子变量交接，步骤索引和实际电平只由 work 修改（初始化除外），不引入 LED 共享锁。status 在已有状态锁下选择图案，避免旧业务阶段覆盖故障显示。

按用户要求保留其他未提交修改，不暂存、不提交。未执行的中间请求合并为最新状态，不保证播放每次瞬时切换。

后续范围修正：仅保留初始化、运行、故障三个指示状态，删除常灭和 ATTENTION 预置图案；未初始化不选择图案。保留循环步骤机制，按实际业务需要扩展。

# 故障上报使用阶段、错误码、描述和最终动作

Status: resolved

## 用户决定与实现

2026-10-24，用户确认采用四项显式上报接口，删除故障来源枚举和映射表。

```c
status_report_fault(STATUS_INIT, err, "输入初始化失败",
                    CONFIG_APP_FAULT_INPUT_INIT_ACTION);
```

- 故障阶段仅为初始化或运行；原有细分业务阶段保留用于采样流程与指示灯编排。
- 描述使用常量或常驻字符串，保存指针，不复制、不动态格式化。
- 删除 `enum status_fault` 及 `policies[]`。调用点直接传入配置动作或明确的复位动作，
  上报函数不比较描述、不查询来源策略、不改写调试动作。
- Kconfig 保留集中配置；调试禁用看门狗时，未显式设置的普通动作默认留驻。
  显式 RESET 仍执行，喂狗错误直接请求复位。
- 指示灯初始化动作独立为 `LED_INIT_ACTION`，默认沿用非继续的 LED 动作，
  运行期 LED 选择继续时，初始化默认复位。初始化阶段的继续请求视为无效参数。
- 快照保存首错描述、阶段、错误和时间，以及当前终止描述与动作。首错不覆盖，
  重复终止动作幂等；任何显式复位请求可将 HOLD 升级为 RESET。
- 调用点、日志、中文 Doxygen、领域术语和故障策略文档同步迁移。

本轮保留用户在 `status_init()` 中调整锁位置的既有改动，仅提交本轮接口变更。
原补丁保存在工作区 `build/IDU-pre/fault-interface/user-status.patch`。

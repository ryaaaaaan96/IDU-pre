# 简化 watchdog 处理路径

目标是减少隐含规则和重复路径，不单纯替换字段名称。保持四参数故障上报、只读回调、私有复位、三倍检查有效期、工作队列检查及无模块锁的喂狗定时器。

- 删除按首次任务登记推断阶段。内部监控故障统一 RESET/200 ms，初始化函数仍返回错误，由调用方主动上报 HOLD。不自动登记任何任务。
- 单一原子模式控制检查与喂狗，GPIO 失败单独锁存；不维护 initialized/stopped/checking/registered/notified/reset_started 或 FEED_* 组合。
- 故障记录只保留一份。内部事件入队、工作队列消费并通知一次；查询不消费、不切换模式。序号仅维护诊断先后关系。
- 线程与 ISR 使用相同停止路径；非监控模式不检查/续期，HOLD 不取消复位，STOPPED 不因 HOLD 恢复。
- 显式 HOLD/RESET 抑制尚未投递的旧任务/CHECK，新的 GPIO 故障仍可升级。延时复位 0 立即、上限 60 秒、重复只能提前规则保持。

按用户要求，修改验证后保留未提交工作树供审阅。

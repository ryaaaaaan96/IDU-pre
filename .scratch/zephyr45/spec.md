# Zephyr 4.5.0 Modbus 适配

工作区由用户更新至 v4.5.0，SDK 1.0.1 已安装。
本任务修改应用自有模块，保持 Zephyr / MCUboot / HAL 依赖源码只读。

## 目标

- 对比 4.4.2 与 4.5.0 的 RAW、核心、串口和服务端源码，调整构建副本扩展。
- 自有 RAW 继续 APP 线程同步处理；其他接口遵循官方队列配置。
- 保留标准功能码边界修复、整笔访问和 IAP 超长帧路由契约。
- 验证独立 Modbus、transmit、产品端口、IAP 组合及目标构建。

不改变产品点表、Flash 布局、参数格式或升级线协议。

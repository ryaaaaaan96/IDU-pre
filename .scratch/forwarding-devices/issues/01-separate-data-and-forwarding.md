# 分离数据设备与虚拟转发设备配置，并实现按入口隔离

## 目标

按[已接受规格](../spec.md)实施两类配置。数据设备定义 process 和可选 collect；
虚拟转发设备独立定义北向逻辑口、转发表、协议段和广播策略。
用户已认可结构示例，本任务无需额外 triage。

## 验收条件

- [ ] 应用只维护两类声明，不再把转发表或 IAP 段挂到本地数据设备，也不重复维护寄存器服务关联。
- [ ] 虚拟转发设备无需 process 表或独立数据池；数据设备与信号 ID 及其 NVS 值保持不变。
- [ ] 普通读写、协议段分派与冲突校验按入口选择；两个入口复用同地址能访问不同测点，且不能串写。
- [ ] 本地及远端 10、11 的采集、缓存读取、命令与持久下发继续工作，零周期和 16 位毫秒周期语义保持。
- [ ] 北向拨码站号、应用端口编排和同线 RS485 事务仲裁保持；IAPv3 地址段、大载荷与广播行为保持。
- [ ] 沿用完整报文输入、南向回调及 DP 公共查询完成集成验证，相关模块可选构建和完整回归通过。
- [ ] IDU／MCUboot／IAPv3 构建、验签和导出通过，文档及接口调用者同步迁移并记录资源变化。

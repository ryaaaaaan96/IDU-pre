# 05：LED 调度归属

目标：把 LED 的节奏和故障显示知识集中到现有 status，main 保留采样周期与休眠。

行为前提：Q5；见[规格](../spec.md)。Q5 已确认 LED 独立表示运行状态，不证明采样活性。

## 验收条件

- [x] main 不再直接读取或维护 LED 下一翻转时间。
- [x] LED 调度满足已接受的时限语义，启动/故障显示具有明确优先级。
- [x] 验证同步采样耗时、迟到调度、输出失败与终止故障的交互。
- [x] 不为单个 LED 引入没有实际用途的通用框架。
- [x] 执行方式依据上下文约束、抖动要求及 RAM 成本选择。
- [x] 分开记录模拟器时序验证与实板波形结果。

## Comments

2026-10-24：范围已授权；当前 main/status 共同维护 LED 调度，未测得实板抖动。

## Answer

LED 调度集中在 status 的 delayable work，复用系统工作队列，main 仅维护采样节奏。采样阻塞时独立翻转、队列延迟跳过错过的边沿、故障常亮及输出错误策略通过测试，acquisition 最终 19/19。普通调度抖动符合约定，不作硬实时承诺。

代码及本地验收完成。完整命令与范围见 [验证记录](../validation.md)；实板 RS485/LED 波形、外狗与复位链、并发堆峰值和栈余量未验证，仍需实物验收。

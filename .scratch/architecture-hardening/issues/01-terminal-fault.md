# 01：本地终止故障收敛

目标：由现有 status 与协议装配集中管理本地终止故障后的整机结果，不再以 main 返回等同于系统停止。

行为前提：Q1、Q2；见[规格](../spec.md)。故障留驻时允许的操作与在途操作处置尚未确认。

## 验收条件

- [ ] 调试与常规构建下的已接受故障行为都有可观察结果。
- [ ] 首个故障保留；旧缓存不会被不加区别地作为正常业务结果返回。
- [ ] 验证部分初始化失败、运行期发布失败、LED 输出失败。
- [ ] 保留远端离线、存储降级与显式任务登记规则。
- [ ] 本地运行任务和协议接入在真实装配测试中接受故障验证。
- [ ] 记录实板复位、故障指示与调试留驻的验证范围。
